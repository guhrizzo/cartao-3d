# Nubank

Página conceitual sobre o Nubank, com conta, Pix, Caixinhas e cartão. O cartão no hero é uma ilustração interativa. GSAP cuida da rolagem e das transições. O preloader aparece a cada carregamento, com luz violeta e o percentual abaixo da barra. Leva pelo menos dois segundos para completar e aguarda os recursos do hero por até sete segundos.

## Rodar localmente

```powershell
npm ci
npm run dev
```

Abra [a prévia local](http://127.0.0.1:8123). Para gerar a versão estática, execute `npm run build`. O resultado fica em `dist/`.

O acabamento e o nome no cartão ficam em `config.js`. O briefing de criação está em [PROMPT.md](PROMPT.md).
